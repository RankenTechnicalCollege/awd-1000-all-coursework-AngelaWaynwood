First you have to identify the purpose of the website and who is the intended audience. Then you plan the layout and design of the website. This includes color, graphics, and typography. After that you begin creating the website. You have to make sure to design the website for multiplatform display, like phones, tablets, and desktops. The last step is to make sure that you website is accessible to all users, including those with disabilities.


I learned how to plan a website using wireframes and site maps. I also learned about multiplatform display and how to design for accessibility.
